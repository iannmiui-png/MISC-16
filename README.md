usage:
# → fib.png
```
python misc16.py fib.bf 
```
# → fib.pgm
```
python misc16.py fib.bf --pgm
```
# build fib.png, then run it
```
python misc16.py fib.bf --run
```
# run without writing an image
```
python misc16.py run fib.bf
```
# explicit output name
```
python misc16.py fib.bf out/name.png
```

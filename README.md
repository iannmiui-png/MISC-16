usage:
```
python misc16.py fib.bf               # → fib.png
```
```
python misc16.py fib.bf --pgm         # → fib.pgm
```
```
python misc16.py fib.bf --run         # build fib.png, then run it
```
```
python misc16.py run fib.bf           # run without writing an image
```
```
python misc16.py fib.bf out/name.png  # explicit output
```
